# Few-day private trial

Agree timezone, lateness and quiet-hour expectations first. Examples stay synthetic unless user supplies real events. Do not duplicate a real reminder for testing.

| Trial | Observable outcome |
| --- | --- |
| Day 1: real text task and hypothetical event | Task saved; example creates no timer |
| Day 1: today 18:00 with unset zone | Clarifies zone, stores explicit date and repeats zone |
| Day 1: prepare before agreed event | Agreed effort/buffer, correct prepare time, persisted reminder ID |
| Day 1: idle window then short due test | Zero idle admissions, one due admission, actual send distinct from receipt |
| Day 2: multiple PR prerequisites | Partial report leaves blockers; final report explains release unlock without executing |
| Day 2: forgotten context | Bounded source lookup/provenance, unknown current state disclosed |
| Day 2: update/snooze/cancel | Stale queued reminder cannot send |
| Day 3: contextual task due | Recovers current blockers/provenance, useful generated next step through one wrapper; no execution |
| Day 3: contextual cancellation/change | Current fingerprint checked; changed draft rejected or irrelevant source dismissed without sending |
| Day 3: permitted self-follow-up | One child per parent, budget/deadline/min spacing inherited; duplicate command returns same child |
| Day 3: no follow-up permission | No autonomous child or periodic model wake |
| Day 3: restart/expiry/failure/uncertainty fixtures | Relevant catch-up, no replay confirmed send or blind uncertain retry |
| Once bot configured: Owner text/voice and Telegram test | Verified binding/modality, actual receipt, unauthorized recipient rejection |

Capture concise defects/corrections, not raw transcripts. After several days review timing usefulness, prep estimates, volume and misses/duplicates; change demonstrated problems. Keep persistent assistant, room and evidence. REVIEW does not authorize deletion/reset.
